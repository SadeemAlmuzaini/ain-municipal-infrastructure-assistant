# 🏙️ Ain – AI Powered Municipal Infrastructure Assistant

## Overview

Ain is a multi-agent AI assistant developed during the **Agentic AI Program** at the **Saudi Digital Academy**.

The project is designed to assist municipalities in processing citizen infrastructure reports by analyzing submitted information and generating structured reports that support faster and more organized decision-making.

---

## Key Features

- Analyze municipal infrastructure reports
- Extract issue details automatically
- Classify issue type
- Determine report priority
- Generate structured reports
- Multi-Agent workflow using CrewAI

---

## Technologies Used

- Python
- CrewAI
- GPT-4o-mini
- Gradio
- Google Sheets

---

## Project Workflow

1. Citizen submits an infrastructure report.
2. AI analyzes the report.
3. The system extracts the issue details.
4. The issue is classified and prioritized.
5. A structured report is generated for follow-up.
